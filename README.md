# Flutter To-Do App (Local Persistence)

A simple To-Do List application built with Flutter. It supports:
- Add new tasks with a title
- View tasks in a scrollable list
- Mark tasks as complete
- Delete tasks

## How to Run


### Prerequisites
- Flutter SDK installed
- Android Studio (or VS Code) + Android emulator / physical device

### Steps
```bash
# 1) Get dependencies
flutter pub get

# 2) Run the app
flutter run
```

### Notes about the project structure
This ZIP contains the Flutter `lib/` code, configuration files, and screenshots.
If you need to regenerate missing platform folders (Android/iOS) on your machine, run:
```bash
flutter create .
flutter pub get
flutter run
```
